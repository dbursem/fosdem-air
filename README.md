This is an ESPHome profile for the FOSDEM26-AIR device. It's very much a work-in-progress.

# how to flash
see https://esphome.io/

# Captive portal 
When there's no wifi connection, the device will start a captive portal you can connect to, to setup wifi.

# Web interface
Once running you can visit the webinterface to change some parameters (like the callback url) or just to monitor the sensors.
